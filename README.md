# vscp-cli

**This is  work in progress.**

VSCP command line tools 

This is a command-line tool for VSCP (Very Simple Control Protocol) that allows you to send and receive events from a VSCP daemon or device using the supported transports for VSCP. It is written in C and provides a simple interface for interacting with VSCP networks.

## vscpsend - Send VSCP events to a VSCP daemon or device.

## vscprcv - Receive VSCP events from a VSCP daemon or device.

## vscpgen - Generate VSCP events based on a given configuration.
